# Min v1.0.1 Release Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Publish the iteration-25 Min checkpoint as GitHub release `min-v1.0.1` after legacy JSON replay reaches zero, with all accepted work integrated into `main` and obsolete branches removed.

**Tech Stack:** C++20, CMake/CTest, Git, GitHub CLI, canonical JSON run artifacts

**Spec:** `docs/superpowers/specs/2026-08-31-binary-replay-segments-design.md` plus the approved release gates in the 2026-08-31 Min training session

## Global Constraints

- Do not apply the next self-play operating-point experiment before legacy JSON replay reaches zero.

- Preserve the 1,000,000-sample replay capacity, 128 simulations, and the current 2.9-pass training ratio through iteration 25.
- Do not rewrite published history or force-push.
- Inspect unique commits before deleting any local or remote branch.
